## Changes NOT visible as markup

latexdiff marks prose, so these do not read as word-level edits:

- **All 20 tables** now use the fully bordered grid of template page 11 instead
  of booktabs. In the marked PDF they appear as large red/blue blocks rather
  than readable edits.
- **Row height** unified at `\arraystretch{1.25}`. Table 3.1 had been 1.3 and
  Table 2.1 1.15, which is why 3.1 looked a different size from the rest.
- **Tables 3.2 and 5.1** set in `\small`, as the other wide tables already were.
  The bordered layout restores the outer cell padding that `@{}` suppressed,
  and without this they crossed the right margin.
- **Tables 2.1 and A.2** column specs rebuilt. The first border pass derived
  them by picking out every l/c/r character, which caught the letters inside
  `>{\raggedright\arraybackslash}p{...}` and produced 21- and 28-column tables
  that ran off the page.
- **List of Abbreviations** pinned to single-spaced rows. At the new row height
  its 28 rows no longer fitted under the heading, and the whole unbreakable
  block moved to the next page, leaving the heading on an empty one.
- **Figure 1.2** Gantt bar relabelled "Documentation and defense" →
  "Documentation". The surrounding prose still describes both, as intended.
- **Figure 4.1** rebuilt as a uniform grid. The four samples were capped by
  height, not width, so their widths tracked each image's aspect (1.35 cm to
  1.57 cm), making the top row narrower than the bottom; each narrow image then
  sat centred in a 0.44\linewidth box, which produced the wide gap. They are
  now centre-cropped to square (`*_sq.png`; originals untouched) and set at one
  fixed 3.8 cm size with an explicit 1.1 cm column gap.
- **Figure 4.6** panel images now sit 5 pt above their sublabels instead of 2 pt.

## Not changed, and why

- **Caption gap.** Template page 11 specifies "space before 12 pt", which the
  document already uses. Widening it would depart from the template, so the
  crowding in Figure 4.6 was addressed inside the figure instead.
- **Bold caption labels.** Captions are already normal weight, matching the
  template. Nothing in this report sets them bold.
- **References without a DOI.** Only the web image was removed. The other 18
  DOI-less entries include the C2A dataset paper, YOLO11, the state-space
  papers, the tiny-object assignment papers behind the headline result, the IEA
  Graduate Attributes framework used in Chapter VI, and the GDPR. CVPR, ECCV
  and NeurIPS do not issue DOIs.
