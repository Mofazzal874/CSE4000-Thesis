# Data and method credits

The selected results use C2A and collected real-world imagery. The detection examples use C2A, created by R. A. Nihal, B. Yen, K. Itoyama, and K. Nakadai. The underlying images retain their original rights; these examples do not grant permission to redistribute the dataset.

The detector builds on Ultralytics YOLO11, CBAM attention, multi-scale detection, and distance-based assignment methods. Their software and data licences still apply.

This folder contains result tables, diagrams, selected detection examples, videos, and an arithmetic checker. It does not contain raw datasets, weights, or the training implementation. No blanket licence is applied to the mixed third-party material.
